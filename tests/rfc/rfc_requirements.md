# RFC requirements and their tests

Every sentence of RFC 9260 and RFC 6951 that uses MUST, SHOULD, REQUIRED, SHALL or RECOMMENDED, with the test that checks it. RFC 9260 section 11 is informational and has none. An ID is `<RFC>-<section>-<n>`, the n-th such sentence of that section, and is what each check in `tests/rfc*.cpp` prints.

A requirement is `n/a` when nothing in this stack could satisfy or violate it; the reason is given instead of a test. Results are from the run that generated this file; rerun `make test` for the current ones.

Totals: 526 requirements, 466 passing, 29 failing, 31 not applicable.
